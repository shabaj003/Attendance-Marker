About Class Keys

What is a class key?

A unique 6-character code generated when you click Start Class. Students use this code to mark attendance for that day only.

Key Features:

  • Generated every day when class is started
  • Valid only during active class time
  • Different key every day
  • Prevents unauthorized attendance marking

Example: Class Key: ABC123
